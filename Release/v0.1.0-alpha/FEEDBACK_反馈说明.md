# 反馈说明

请优先反馈能稳定复现的问题。描述越具体，修复越快。

## 推荐格式

```text
版本号：
你想做什么：
实际发生了什么：
期望结果：
是否能稳定复现：
复现步骤：
截图/阵容/日志：
```

## 示例

```text
版本号：v0.1.0-alpha
你想做什么：用自定义卡池剔除某个随从后进入对局
实际发生了什么：刷新商店后仍然出现该随从
期望结果：被剔除的随从不再出现
是否能稳定复现：是，重复 3 次都出现
复现步骤：
1. 打开卡池版本控制
2. 复制默认版本并命名
3. 搜索该随从并取消勾选
4. 保存并进入对局
5. 连续刷新商店
截图/阵容/日志：附截图
```

## 优先级

- P0：无法启动、主流程卡死、存档/配置损坏。
- P1：战斗结果明显错误、卡池版本不生效、关键按钮不可用。
- P2：UI 明显难用、文字挤压、缺图影响判断。
- P3：英雄/伙伴效果不精确但可绕过。
- P4：文案、排版和小体验问题。
