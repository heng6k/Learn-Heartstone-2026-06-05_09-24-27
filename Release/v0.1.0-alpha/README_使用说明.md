# Learn Heartstone v0.1.0-alpha 使用说明

这是一个非官方的单人酒馆训练工具，用来复盘、构造局面、测试站位、验证机制和查找问题。

当前版本是 Alpha，不是完整官方模拟器，也不是完整新手教程。请把它当成可试玩的测试包。

## 启动方式

1. 解压 `BattlegroundsTrainer_v0.1.0-alpha_win.zip`。
2. 双击 `Learn Heartstone.exe`。
3. 如果 Windows 弹出安全提示，确认来源是你下载的 GitHub Release 后再继续。

## 基础流程

1. 在入口页点击 `酒馆训练器`。
2. 选择本局可用种族。
3. 如需自定义卡池，打开 `卡池版本控制`。
4. 复制默认版本，输入版本名。
5. 用等级、种族/类型、搜索框筛选随从或酒馆法术。
6. 勾选单卡，或用批量按钮剔除/加入当前筛选结果。
7. 点击保存后进入对局。
8. 在训练器内刷新、购买、出售、升级酒馆、进入下一回合。
9. 配置对手后运行战斗。
10. 查看战斗回放、战斗日志和招募日志。

## 卡池版本控制

- 默认版本是只读版本。
- 自定义版本可以命名、保存，并在进入对局时生效。
- 随从和酒馆法术都支持筛选和剔除。
- 列表初始显示一部分卡牌，滚动到底部会继续加载。
- 双打/BGDUO 卡牌不进入当前单人卡池版本。

## 小窗口调试

右下角有 `窗口比例` 按钮，可切换：

- 恢复大屏 `1920x1080`
- 小窗 `994x384`
- `16:9 1280x720`
- `4:3 1024x768`
- `9:16 540x960`

如果在 Unity Editor 中运行，它也会尝试同步 Game View 的比例预设；在独立 Windows 包中，它会切换窗口分辨率。
