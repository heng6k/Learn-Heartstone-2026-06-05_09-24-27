# v0.1.0-alpha 更新记录

## 主要内容

- 新增 Unity 组件化酒馆训练器主流程。
- 支持单人酒馆训练：刷新、购买、出售、冻结、升级、下一回合。
- 支持战斗模拟、战斗回放、战斗日志和招募日志。
- 支持对手阵容编辑和卡牌库工具。
- 支持英雄、英雄技能、伙伴和部分复杂机制的第一批实现。

## 卡池版本控制

- 支持卡池版本弹窗模式。
- 支持复制默认版本并重命名。
- 支持随从和酒馆法术的勾选启用/剔除。
- 支持等级、种族/类型、搜索筛选。
- 支持批量剔除/加入当前筛选结果。
- 支持滚动到底部继续加载。
- 已排除双打/BGDUO 卡牌。
- 支持进入对局后应用自定义卡池。
- 支持未保存切换确认提示。

## 调试与测试

- 新增右下角窗口比例调试按钮，包含小窗检查和恢复大屏选项。
- 新增 Unity Editor Game View 比例预设工具。
- AlphaSmoke batch 冒烟测试通过：`13/13`。
- 非 30 分钟 soak 的 EditMode 门禁通过：`399/399`。

## 仍在改进

- 英雄/伙伴完整精确度。
- 小窗口视觉体验。
- 缺图定位和资源审计。
- 卡池批量操作撤销。
- 更完整的问题反馈导出。
