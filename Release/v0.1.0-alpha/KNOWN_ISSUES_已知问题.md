# v0.1.0-alpha 已知问题

## 定位限制

- 这是单人酒馆训练器，不支持双打系统、传递、队友奖励或真实 8 人大厅。
- `BGDUO` 卡牌属于项目外范围，不会进入单人卡池。
- 这不是官方产品，也不保证所有行为与官方完全一致。

## 玩法与机制

- 部分英雄、伙伴和复杂法术仍是代理实现或框架优先实现。
- 一些战斗中即时触发、击杀归属、亡语 payload、对手历史和任务/饰品系统仍不完整。
- 部分官方机制当前只覆盖项目已有的测试路径。

## 卡池版本控制

- 版本名输入框是失焦保存，卡牌勾选需要手动点击保存，保存规则还不完全一致。
- 随从和法术共用一组等级/种族筛选，切换标签时可能出现筛选结果为空。
- 批量剔除没有撤销按钮。
- 缺图时提示仍较简单。

## UI 与显示

- 小窗口布局仍需要观察，尤其是弹窗文字挤压、筛选区宽度和滚动手感。
- 部分按钮和面板仍偏工程化。
- 一些图片资源可能缺失或比例不理想。

## 反馈与复现

- 当前还没有一键导出完整复现包。
- 复杂问题请手动附截图、操作步骤、当前阵容、卡池版本和日志描述。
