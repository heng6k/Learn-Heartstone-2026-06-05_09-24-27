# 示例场景

这些场景用于快速试用和反馈。

## 1. 基础酒馆流程

1. 进入酒馆训练器。
2. 刷新商店。
3. 购买一个随从。
4. 将随从拖到战场。
5. 出售一个随从。
6. 进入下一回合。

## 2. 卡池版本验证

1. 打开卡池版本控制。
2. 复制默认版本并命名。
3. 搜索一个随从并取消勾选。
4. 保存并进入对局。
5. 连续刷新，确认该随从不再出现。

## 3. 筛选与滚动加载

1. 打开卡池版本控制。
2. 选择随从标签。
3. 按等级和种族筛选。
4. 滚动到底部触发继续加载。
5. 批量剔除当前筛选结果并保存。

## 4. 酒馆法术

1. 在卡池版本控制中切到法术标签。
2. 搜索一个酒馆法术。
3. 剔除并保存。
4. 进入对局后确认该法术不会出现在酒馆法术池。

## 5. 对手阵容与战斗

1. 进入训练器。
2. 使用工具添加或编辑对手随从。
3. 调整己方站位。
4. 点击战斗。
5. 查看战斗回放和战斗日志。

## 6. 小窗口视觉检查

1. 点击右下角 `窗口比例`。
2. 选择 `小窗 994x384`。
3. 打开卡池版本控制。
4. 检查弹窗、筛选、滚动和按钮是否仍可读可点。
5. 再次点击 `窗口比例`，选择 `恢复大屏 1920x1080`。
