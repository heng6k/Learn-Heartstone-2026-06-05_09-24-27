# GitHub Release 文案：v0.1.0-alpha

## 标题

```text
v0.1.0-alpha - 单人酒馆训练器首个可试玩包
```

## 正文

这是 Learn Heartstone 的第一个 Windows alpha 测试包，目标是让玩家可以在单人酒馆环境中构造局面、测试卡池、运行战斗并反馈问题。

### 下载

下载附件：

```text
BattlegroundsTrainer_v0.1.0-alpha_win.zip
```

解压后运行：

```text
Learn Heartstone.exe
```

### 本版重点

- 单人酒馆训练主流程。
- 刷新、购买、出售、冻结、升级、下一回合。
- 战斗模拟、回放和日志。
- 卡池版本控制：命名、筛选、剔除、保存、滚动加载。
- 排除双打/BGDUO 卡牌。
- 右下角窗口比例调试工具，方便检查小窗口 UI，并可一键恢复 `1920x1080`。

### Alpha 说明

这不是正式版，也不是完整官方模拟器。部分英雄、伙伴、复杂法术和战斗细节仍是简化或代理实现。请优先反馈能稳定复现的问题，并附截图、操作步骤和日志描述。

### 已验证

- 非 30 分钟 soak 的 EditMode 门禁：`399/399` 通过。
