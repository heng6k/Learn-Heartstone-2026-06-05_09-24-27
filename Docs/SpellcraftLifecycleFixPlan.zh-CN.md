# 塑造法术生命周期完整修复方案

## 1. 文档目标

统一修复“海上双雄”及其他塑造随从的法术生成、手牌容量判断、回合结束清理和临时效果清理逻辑，使其行为与实际酒馆战棋一致。

本次修复覆盖以下问题：

- 海上双雄从手牌打到场上后没有立即获得塑造法术。
- 其他塑造随从可能同样只在新回合开始生成法术。
- 满手牌时的生成顺序和失败规则不明确。
- 未使用的临时塑造法术没有在当前回合结束时立即丢弃。
- “未使用法术卡牌的清理”和“已经施放的临时效果清理”容易被错误地放在同一个时机。

## 2. 当前根因

当前主要生成入口是新酒馆回合开始时执行的 `AddSpellcraftFromBoard()`。该方法遍历场上随从，再通过 `AddSpellcraftFromSource()`生成对应法术。

从手牌打出塑造随从时，现有上场流程没有调用同一生成入口。因此新打出的海上双雄不会立即提供法术，只能等到下一个酒馆回合。

当前临时塑造法术通过 `temporary_spellcraft_card` 标签识别，但清理主要发生在下一回合初始化阶段，没有作为“结束当前回合”的第一项操作执行。

## 3. 统一生命周期

塑造法术生命周期必须拆分为四个独立阶段：

1. 塑造随从上场时立即尝试生成法术。
2. 每个新酒馆回合开始时，场上的塑造随从再次尝试生成法术。
3. 当前酒馆回合结束时，最优先丢弃所有未使用的临时塑造法术卡牌。
4. 下一酒馆回合开始时，清除上一轮已经施放到随从身上的临时塑造效果。

其中第3步和第4步绝对不能合并。法术卡牌要在进入战斗前消失，但已经施放的临时效果必须参与本轮战斗。

## 4. 完整行为规则

### 4.1 塑造随从上场时立即获得法术

玩家从手牌打出具有塑造能力的随从后，按以下顺序处理：

1. 从手牌移除该随从。
2. 将随从成功放入玩家战场。
3. 完成必要的上场状态初始化。
4. 判断它是否属于当前已实现的塑造法术来源。
5. 检查手牌是否仍有空位。
6. 有空位时立即生成对应塑造法术。
7. 没有空位时跳过本次生成，不建立待领取或延迟补发状态。

手牌容量必须在随从离开手牌并进入战场后判断。因此玩家原本有10张手牌，其中一张是即将打出的塑造随从时，打出后已经空出位置，应当正常获得法术。

只有触发生成的实际时刻手牌仍然达到上限，才判定为满手牌。

### 4.2 每个新酒馆回合再次获得法术

进入新酒馆回合时，先完成上一轮临时效果清理，再遍历场上所有塑造随从生成本回合法术。

规则如下：

- 按玩家战场从左到右的稳定顺序处理。
- 每个塑造随从独立尝试一次。
- 普通塑造随从通常生成一张普通法术。
- 金色塑造随从通常生成一张强化法术，不默认生成两张。
- 如果某张卡的正式文本明确要求多张法术，则按卡牌文本处理。
- 手牌剩余几个位置，最多只能成功生成几张。
- 因满手牌失败的法术不进入等待队列。
- 玩家之后使用卡牌腾出位置，也不会补发本次错过的法术。

### 4.3 回手并重新打出

塑造随从被移回手牌后再次打出，视为一次新的打出行为。

- 手牌有位置时再次生成对应塑造法术。
- 仅调整战场位置不触发。
- 直接召唤、复制或变形到战场默认不触发“打出时生成”，除非该效果明确视为打出。
- 三连后重新从手牌打出金色塑造随从，应生成金色版本对应的强化法术。

### 4.4 回合结束首先丢弃未使用的塑造法术

这是本次修改的硬性优先级要求。

玩家结束酒馆回合时，必须先执行临时塑造法术清理，再执行任何其他回合结束效果。

规定的结束回合顺序为：

1. **丢弃手牌中所有未使用的临时塑造法术。**
2. 执行其他“回合结束时”随从效果。
3. 执行饰品、英雄技能、任务、畸变等回合结束效果。
4. 生成或处理其他合法的回合结束奖励。
5. 创建战斗快照并进入战斗阶段。

第一步必须是整个回合结束事件中的最高优先级，不能被普通回合结束触发器插到前面。

清理范围：

- 删除手牌中带有 `temporary_spellcraft_card` 标签的卡牌。
- 不删除普通酒馆法术。
- 不删除鲜血宝石、铸币或其他非塑造生成牌。
- 不删除已经被特殊机制转换成永久卡牌的塑造法术。
- 清理不算施放法术。
- 清理不触发“施放法术后”效果。
- 清理不触发普通弃牌收益。
- 清理不写入延迟领取队列。

优先清理的直接影响：如果某个普通回合结束效果会根据当前手牌数量、最左侧手牌或手牌中的法术进行计算，它看到的必须是已经移除未使用塑造法术后的手牌状态。

### 4.5 已施放的临时效果必须保留经过战斗

结束回合时只删除未使用的法术卡牌，不能删除已经施放到随从身上的临时效果。

例如海上双雄的法术已经施放后：

- 目标随从保留临时亡语进入战斗。
- 本轮战斗中死亡时正常召唤螃蟹。
- 不能因为结束回合优先清理而提前移除亡语。
- 临时效果在下一次进入酒馆时清除。

如果目标原本已有亡语，清理时只能移除塑造法术临时添加的亡语，不能移除目标原有亡语。

### 4.6 满手牌处理

| 场景 | 预期结果 |
|---|---|
| 9张手牌时打出塑造随从 | 随从离手后正常生成法术 |
| 10张手牌且其中一张是要打出的塑造随从 | 打出后有空位，正常生成法术 |
| 新回合开始时手牌为10张 | 所有塑造来源均无法生成 |
| 新回合只有1个空位，场上有3个塑造随从 | 最左侧来源成功，后两个失败 |
| 生成失败后本回合再腾出位置 | 不补发 |
| 塑造法术生成后使手牌达到10张 | 后续来源停止生成 |
| 手牌为空但有多个塑造随从 | 按场上顺序全部生成，直到达到上限 |

### 4.7 海上双雄具体规则

海上双雄的 `CardId` 为 `BG27_004`。

普通版本：

- 从手牌打出后立即获得一张0费塑造法术。
- 每个新酒馆回合再获得一张。
- 法术使一个友方随从获得临时亡语：召唤一只3/2野兽螃蟹。

金色版本：

- 同样生成一张法术。
- 法术使目标获得临时亡语：召唤一只6/4野兽螃蟹。

效果叠加：

- 目标原有亡语必须保留。
- 海上双雄提供的亡语作为额外亡语存在。
- 多次施放需要按正式游戏规则确认是多个独立亡语还是更新同一临时亡语；实现前不得通过单一布尔标签误吞合法叠加。
- 临时亡语参与当前战斗，下一酒馆回合再移除。

## 5. 其他塑造随从排查范围

所有通过 `AddSpellcraftFromSource()`生成法术的来源都需要进行同一轮检查，至少包括：

- 海上双雄。
- 礁石乐手。
- 深海垂钓者。
- 深蓝刃鳞龙人等现有深蓝塑造来源。
- 火山访客。
- 霜寒女祭司。
- 当前版本中其他带有塑造关键字或 `spellcraft_generator` 标签的随从。
- 时空酒馆、饰品或特殊机制提供的塑造来源。

每个来源需要确认：

- 上场时是否立即生成。
- 新回合是否生成。
- 普通和金色的数量、数值是否正确。
- 生成牌是否带有 `temporary_spellcraft_card`。
- 是否正确处理手牌上限。
- 未使用法术是否在回合结束第一优先级清除。
- 已施放效果是否正确持续到下一酒馆回合。

## 6. 实现约束

### 6.1 复用统一生成入口

上场触发和回合开始触发应复用 `AddSpellcraftFromSource()`或等价的共享入口，避免每张纳迦分别实现一套逻辑。

共享入口应返回实际生成数量，便于日志和测试确认满手牌行为。

### 6.2 明确事件阶段

建议将生命周期拆成语义明确的入口：

- 塑造随从成功上场后的生成入口。
- 酒馆回合开始时的临时效果清理入口。
- 酒馆回合开始时的塑造法术生成入口。
- 酒馆回合结束最优先执行的未使用塑造法术清理入口。

禁止继续使用一个名称模糊的方法同时清理手牌卡牌和场上临时效果。

### 6.3 不引入补发队列

满手牌导致的生成失败是最终结果。不要新增待领取列表、延迟生成状态或手牌空位监听器。

### 6.4 保持确定性顺序

多个塑造来源必须按场上顺序处理，不能依赖字典枚举顺序或不稳定的对象查找顺序。

## 7. 推荐事件顺序

### 7.1 打出塑造随从

```text
验证可打出
→ 从手牌移除
→ 放入战场
→ 处理战吼及上场事件
→ 尝试生成该随从的塑造法术
→ 处理其他“随从打出后”效果
→ 刷新界面
```

如果现有正式触发顺序要求“打出后效果”先于塑造生成，需要通过实际酒馆规则确认；无论具体相对顺序如何，塑造生成必须发生在本次打出流程内，不能延迟到下回合。

### 7.2 结束酒馆回合

```text
结束回合请求
→ [最高优先级] 删除未使用的临时塑造法术
→ 其他随从回合结束效果
→ 英雄、任务、饰品、畸变等回合结束效果
→ 战斗前状态结算
→ 创建战斗快照
→ 进入战斗
```

### 7.3 进入下一酒馆回合

```text
战斗结束
→ 清除上一轮已经施放的临时塑造效果
→ 处理回合开始资源和商店刷新
→ 场上塑造随从按顺序生成本回合法术
→ 其他回合开始效果
→ 进入可操作状态
```

## 8. 验收测试

### 8.1 上场生成

- 普通海上双雄打出后立即获得 `SURF_N_SURF_SPELL`。
- 金色海上双雄打出后立即获得强化版本数据。
- 其他塑造随从打出后获得各自对应法术。
- 回手后重新打出可以再次生成。
- 直接移动战场位置不生成。

### 8.2 手牌容量

- 10张手牌中打出塑造随从后，利用空出的手牌位置正常生成。
- 新回合满手牌时不生成。
- 只有一个空位时，多个来源只允许最左侧来源成功。
- 失败后腾出位置不补发。

### 8.3 回合结束最高优先级

- 结束回合后，其他回合结束效果执行前，所有 `temporary_spellcraft_card` 已从手牌移除。
- 依赖手牌数量的回合结束效果读取到清理后的手牌数量。
- 依赖最左侧手牌的效果不会选中即将过期的塑造法术。
- 清理不增加法术施放计数。
- 清理不触发施法收益、弃牌收益或任务进度。
- 普通酒馆法术和其他生成牌不受影响。

### 8.4 已施放效果

- 海上双雄法术赋予的亡语可以进入战斗。
- 普通版本死亡召唤3/2螃蟹。
- 金色版本死亡召唤6/4螃蟹。
- 下一酒馆回合清除临时螃蟹亡语。
- 目标原有亡语不会被清除。
- 永久保留塑造效果的特殊机制不会被普通临时清理误删。

### 8.5 生命周期连续性

- 上场立即生成一次，下一酒馆回合再生成一次。
- 回合结束未使用法术消失，不会带入战斗。
- 战斗后不会残留上一回合未使用法术。
- 新回合清理旧效果后，再生成新的本回合法术。

## 9. 完成标准

只有同时满足以下条件，本修复才算完成：

- 海上双雄上场后立即获得法术。
- 所有已实现塑造来源遵守相同生成规则。
- 满手牌行为稳定且不存在延迟补发。
- 回合结束时，未使用塑造法术以整个结束回合流程的最高优先级清除。
- 清理后才执行其他回合结束效果。
- 已施放临时效果仍可参加战斗。
- 下一酒馆回合正确清除旧效果并生成新法术。
- 普通法术、永久塑造效果和目标原有效果不被误删。
- 对上述路径具备可运行的 EditMode 回归测试。
