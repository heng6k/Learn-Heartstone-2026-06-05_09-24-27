# 随从右键自定义编辑修改文档

## 目标

把当前卡牌底部的“最多 3 个中文关键词短标签”删除，改成两套更舒服的交互：

1. 鼠标悬停随从时，弹出一个小窗显示该随从的全部关键词和说明。
2. 右键己方或敌方战场随从时，打开自定义编辑面板，允许直接输入身材并勾选关键词。

这个功能服务于战棋模拟和战斗测试。玩家可以先把一个随从调成想要的攻击、生命和关键词，再一键把这套配置复制到己方全体或敌方全体随从。

## 本次需求

### 删除底部关键词短标签

当前全卡图随从底部会显示 `嘲讽 圣盾` 这类文字条。这个显示方式要删除，避免遮挡卡图，也避免卡面变成文字堆叠。

删除后，卡面常驻信息只保留：

- 酒馆等级
- 攻击
- 生命
- 必要操作按钮

关键词不再压在卡图底部。

### 悬停显示关键词小窗

鼠标放到随从上时，弹出一个轻量小窗，显示该随从当前拥有的全部关键词。

小窗内容示例：

```text
关键词
嘲讽：敌人必须优先攻击该随从。
圣盾：第一次受到伤害时免疫该伤害。
复生：死亡后以 1 点生命值复活一次。
```

显示规则：

- 只在鼠标悬停时显示。
- 鼠标移出后自动关闭。
- 小窗跟随卡牌附近显示，不遮挡攻击和生命角标。
- 没有关键词时不显示小窗，或者显示 `无关键词` 的简短空态。
- 小窗显示当前有效关键词，优先读取随从的 `Keywords`，不要只读原始卡牌的 `OfficialKeywords`，否则自定义后看不到新效果。

### 右键随从打开自定义编辑

右键目标范围：

- 己方战场随从
- 敌方战场随从

第一版不把商店、手牌、发现选项纳入右键编辑。它们不是这次战斗模拟自定义的核心，后续可以复用同一个面板扩展。

右键行为：

1. 右键随从。
2. 自动选中该随从。
3. 打开 `随从编辑` 面板。
4. 面板默认填入该随从当前攻击、生命和关键词。

左键仍保留原来的选中、拖动、购买、出售等行为。

## 编辑面板

建议面板内容：

```text
随从编辑
目标：小瞎眼（己方 1 号位）

攻击 [ 50 ]
生命 [ 50 ]

关键词：
[ ] 嘲讽   [ ] 圣盾   [ ] 烈毒
[ ] 复生   [ ] 亡语   [ ] 风怒
[ ] 潜行

[保存当前] [套用己方全体] [套用敌方全体]
[清空关键词] [取消]
```

按钮行为：

- `保存当前`：只修改右键点中的那个随从。
- `套用己方全体`：把当前面板里的攻击、生命、关键词应用到己方战场全部随从。
- `套用敌方全体`：把当前面板里的攻击、生命、关键词应用到敌方战场全部随从。
- `清空关键词`：只清空面板勾选状态，不立即保存；玩家再选择保存或套用。
- `取消`：关闭面板，不保存。

## 关键词范围

第一版编辑面板只放常用战斗关键词：

| 中文 | 代码关键词 | 说明 |
| --- | --- | --- |
| 嘲讽 | `Taunt` | 敌方攻击优先指向该随从。 |
| 圣盾 | `DivineShield` | 第一次受到伤害时免疫伤害。 |
| 烈毒 | `Venomous` | 造成伤害后消灭受伤目标，通常为一次性效果。 |
| 复生 | `Reborn` | 死亡后以 1 点生命复活一次。 |
| 亡语 | `Deathrattle` | 死亡时触发效果。 |
| 风怒 | `Windfury` | 可以额外攻击一次。 |
| 潜行 | `Stealth` | 未攻击前不容易被普通攻击指定。 |

暂不放入默认编辑面板：

- `Magnetic` / 磁力：它更像打出/合体时的卡牌效果，不作为第一版战场随从自定义关键词。
- `Cleave` / 顺劈：意思是攻击目标时同时伤害目标相邻随从。它属于战斗效果，后续可以作为“高级效果”单独开放，但第一版不放进常用关键词，避免玩家误以为所有随从都能稳定模拟这类攻击模板。
- `Battlecry` / 战吼、`Avenge` / 复仇、`Spellcraft` / 塑造法术等：更偏卡牌文本或触发机制，第一版只在悬停小窗里显示已有信息，不在右键面板中手动勾选。

## 一键套用规则

一键套用使用“面板当前值”，不要求先点 `保存当前`。

例子：

1. 右键己方第一个随从。
2. 攻击输入 `50`，生命输入 `50`。
3. 勾选 `嘲讽`、`圣盾`、`复生`。
4. 点击 `套用己方全体`。
5. 己方战场所有随从都变成 `50/50`，关键词都变成 `嘲讽 + 圣盾 + 复生`。

同理，点击 `套用敌方全体` 就只影响敌方战场，不影响己方。

批量套用是“替换成完全相同的身材和关键词”，不是在原有基础上追加。

## 数据规则

攻击：

- 最小值：`0`
- 建议最大值：`999`
- 输入非法内容时不保存，并在输入框附近提示。

生命：

- 最小值：`1`
- 建议最大值：`999`
- 保存时同时设置：
  - `Health = 输入生命`
  - `MaxHealth = 输入生命`

关键词：

- 保存为精确集合。
- 不保留未勾选的旧关键词。
- 不允许重复。
- 编辑面板写入随从当前有效 `Keywords`。
- 悬停小窗展示随从当前有效 `Keywords`，必要时可补充原始 `OfficialKeywords` 作为说明，但不能覆盖自定义结果。

## 视觉方案

第一版优先保证信息清楚，不做复杂粒子特效。

常驻卡面：

- 保留攻击和生命角标。
- 保留酒馆等级角标。
- 删除底部关键词条。
- 不让任何文字挡住完整卡图主体。

悬停小窗：

- 用深色半透明面板。
- 标题为 `关键词`。
- 每个关键词一行，包含中文名和短说明。
- 最大高度受限，关键词过多时内部滚动。

后续可加的轻量视觉效果：

- 嘲讽：卡牌外框出现更厚的护盾色边框。
- 圣盾：卡面外缘出现金色环或轻微呼吸光。
- 烈毒：攻击角标附近出现绿色毒性高亮。
- 复生：生命角标附近出现淡紫色回魂高亮。
- 风怒：攻击角标附近出现双击提示。
- 亡语：卡牌边缘有紫色脉冲。

这些效果不是第一版必要条件，不能影响右键编辑功能落地。

## 技术方案

### 现有基础

项目已经有可复用的底层能力：

- `MinionPatch` 已支持 `Attack`、`Health`、`MaxHealth`、`Golden`、`Keywords`、`Tribes`。
- `MatchService` 已支持 `UpdateMinion` 和 `UpdateOpponentMinion`。
- 当前工具弹窗已经能对选中卡做 `攻+1`、`攻-1`、`血+1`、`金色`。

因此这次主要是 UI 入口、悬停提示和批量应用体验，不需要重写战斗核心。

### 需要修改的文件

预计修改：

- `Assets/LearnHearthstone/Runtime/Presentation/TavernTrainer/UnityStyle/UnityTavernCardComponent.cs`
  - 删除 `UnityCardKeywordStrip` / `UnityCardKeywordText` 的生成路径。
  - 取消 full-art 卡牌底部关键词短标签。
  - 增加右键回调入口，例如 `onContextAction`。
  - 增加悬停回调入口，例如 `onHoverStart` / `onHoverEnd`，用于显示关键词小窗。

- `Assets/LearnHearthstone/Runtime/Presentation/TavernTrainer/UnityStyle/UnityTavernTrainerController.cs`
  - 在己方/敌方战场卡牌绑定右键编辑回调。
  - 在卡牌悬停时显示关键词小窗，移出时关闭。
  - 增加 `OpenMinionEditor(...)`、`ApplyMinionEditorPatch(...)`、`ApplyPatchToPlayerBoard(...)`、`ApplyPatchToOpponentBoard(...)`。
  - 批量套用时执行一组已有 `UpdateMinion` / `UpdateOpponentMinion` 命令，最后统一刷新 UI。

  - 提供保存当前、套用己方全体、套用敌方全体、清空关键词、取消按钮。

- 新增或复用悬停提示组件
  - 可以新增 `UnityTavernKeywordTooltipComponent.cs`。

- `Assets/LearnHearthstone/Tests/EditMode/UnityTavernTrainerViewTests.cs`

  - 覆盖己方批量。

- `Assets/LearnHearthstone/Editor/UnityTavernPrefabBuilder.cs`
  - 如果卡牌 prefab 内还绑定了关键词文字节点，需要同步移除或停用。

## 验收标准

功能验收：

- 有完整卡图的随从不再显示底部关键词短标签。
- 鼠标悬停随从时显示关键词小窗。
- 鼠标移出随从后关键词小窗关闭。
- 右键己方战场随从会打开编辑面板。
- 右键敌方战场随从会打开编辑面板。
- 输入攻击/生命并保存后，该随从立即显示新身材。
- 勾选关键词并保存后，该随从参与战斗时拥有这些关键词效果。
- 点击 `套用己方全体` 后，己方战场所有随从都变成面板里的身材和关键词。
- 点击 `套用敌方全体` 后，敌方战场所有随从都变成面板里的身材和关键词。
- 己方批量不会影响敌方，敌方批量不会影响己方。
- `磁力` 不出现在第一版右键关键词编辑项里。

视觉验收：

- 右键编辑面板不遮住主要操作栏。
- 悬停关键词小窗不遮住攻击和生命角标。
- 输入框可读，按钮可点。
- Compact 布局下编辑面板不越界。
- 关键词不再以底部文字条形式压在卡图上。

测试验收：

- `UnityTavernTrainerViewTests` 新增测试通过。
- 原有 `RealisticTavernTrainerViewTests`、`SpellCatalogTests` 不回退。
- Unity Console 无项目错误。

## 不在第一版范围

- 不修改原始卡牌数据表。
- 不把自定义身材永久保存到卡牌库。
- 不编辑法术。
- 不做完整粒子特效系统。
- 不把所有机制类效果都做成右键可勾选项。
- 不把磁力作为可勾选关键词。

## 实现顺序建议

1. 先删除底部关键词条，并改测试。
2. 增加悬停关键词小窗。
3. 增加右键回调和随从编辑面板。
4. 接入单体保存。
5. 接入己方/敌方批量套用。
6. 跑 Unity EditMode 回归并清理 Console。

## 已确认规则

- `生命` 输入会同时改当前生命和最大生命。
- `套用己方/敌方全体` 是“替换成完全相同身材和关键词”，不是在原有基础上追加。
- 底部关键词短标签删除后，关键词通过鼠标悬停小窗查看。
- `磁力` 不作为第一版右键可编辑关键词。
