# 酒馆战斗实战差距补足计划

> **给后续执行的 Agent：** 本计划以一二本战斗准确性为第一目标。先补战斗底座，再补单卡机制；不要为了单卡临时绕过攻击顺序、召唤位置和事件队列。

**目标：** 让当前战斗测试从“能跑基础战斗”提升到“可回放一二本核心实战场景”。第一阶段优先修正攻击顺序、召唤位置、死亡结算和战斗日志，第二阶段再补一二本缺失战斗机制。

**当前结论：** 招募阶段调试能力已经可用，但战斗模拟仍偏基础。最大偏差不是单张牌，而是底层规则：攻击者总取第一个存活随从、token 追加到队尾、死亡结算没有携带死亡位置、持续光环不影响后续召唤。

---

## 范围

本计划覆盖一二本单人酒馆战棋，不包含双打机制。

本版要做：

- 战斗攻击指针：同一方不再永远由第一个存活随从攻击。
- 亡语召唤位置：token 尽量填入死亡随从原位置，而不是直接追加队尾。
- 基础死亡结算上下文：死亡结算时保留死亡位置，亡语可以在正确位置召唤。
- 保持已有基础机制：嘲讽、圣盾、剧毒/烈毒、复生、一二本基础亡语。
- 增加测试覆盖攻击轮转、召唤位置、森林游虫、亮喉督军、血色骷髅。

本版暂不做：

- 完整动画时间线。
- 完整复仇、进击、塑造法术、泰蕾苟萨永久保留、永恒骑士全局死亡计数。
- 战斗后给手牌/招募阶段结算的亡语收益，例如通报警告机、钢铁猎人、刺背恶霸。
- 双打“传递/队友”相关机制。

---

## 实战差距清单

优先级 P0：

- 攻击顺序错误：当前每边总取第一个存活随从攻击；真实战斗按攻击指针轮转。
- 召唤位置错误：当前 token 追加到队尾；真实战斗应尽量填死亡随从位置。
- 死亡上下文不足：亡语不知道死亡位置，导致站位、后续攻击顺序和相邻类机制无法准确。

优先级 P1：

- 暮光龙崽：雏龙应立即攻击。
- 风怒：爆裂飓风等随从应能额外攻击。
- 哼鸣蜂鸟：应作为战斗内光环影响后续召唤的野兽，不只是开局一次性 buff。
- 血色骷髅：目标选择不应依赖遍历顺序，应能选择任意友方亡灵。

优先级 P2：

- 进击：飞行专家、贪睡的援护巨龙。
- 战斗后收益类亡语：通报警告机、钢铁猎人、刺背恶霸。
- 受伤触发：巨饿冬鳍鱼人。
- 永久战斗收益：泰蕾苟萨、永恒骑士、星元自动机、古老之魂。

## 第一阶段实现设计

### 攻击指针

在 `CombatEngine` 内部维护双方攻击指针。

规则：

- 初始攻击方仍按现有规则：随从数量多的一方先攻，数量相同玩家先攻。
- 每一方有自己的 `nextAttackIndex`。
- 选择攻击者时，从指针位置开始向后找第一个存活且可攻击的随从。
- 攻击后，该方指针推进到攻击者当前位置之后。
- 如果攻击者死亡或前面随从死亡，指针要根据当前列表长度归一化。

首版不处理：

- 风怒多次攻击。
- “立即攻击”的插队逻辑。

### 召唤位置

死亡结算时不再只把存活随从复制到新列表，而是保留死亡随从原索引。

规则：

- 单个亡语召唤的 token 插入死亡随从原位置。
- 多个 token 按顺序插在该位置开始处。
- 如果战场已满，后续召唤失败。
- 复生随从在原位置复生。

首版折中：

- 同一轮多个随从同时死亡时，按当前列表顺序处理。
- 不做完整的炉石事件栈，只保证基础站位和一二本 token 不空转。

### 战斗日志

新增或保持这些日志点：

- `CombatStarted`
- `攻击`
- `DeathrattleResolved`
- `MinionSummoned`
- `RebornResolved`
- `CombatEnded`

后续可加：

- `AttackPointerAdvanced`
- `ImmediateAttackQueued`
- `AuraApplied`

## 第二阶段单卡顺序

- 暮光龙崽：亡语召唤 3/3 雏龙并立即攻击。
- 风怒：爆裂飓风可额外攻击。
- 哼鸣蜂鸟：战斗光环对后续召唤野兽生效。
- 血色骷髅：目标选择独立于死亡遍历顺序。
- 进击基础队列：飞行专家、贪睡的援护巨龙。
- 战斗后收益类亡语：通报警告机、钢铁猎人、刺背恶霸。

## 验收标准

- Unity EditMode 全绿。
- 新增测试证明：
  - 同一方多个随从时，攻击者会轮转，不会永远第一个随从攻击。
  - 亡语 token 会插入死亡随从原位置。
  - 森林游虫甲虫吃 Tavern 里的甲虫全局加成。
  - 亮喉督军 token 被鲜血宝石变成 2/2 嘲讽。
  - 血色骷髅至少能在常见站位 buff 友方亡灵。
- 不引入双打“队友/传递”机制。
