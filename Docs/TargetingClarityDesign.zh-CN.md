# Targeting Clarity：指向目标可读性设计

## 状态

运行时代码已实现（2026-07-11）。

当前覆盖玩家英雄技能、带 `targeted_spell` 标签的玩家酒馆法术、敌方英雄技能已配置目标，以及战斗回放 `ActorId` / `TargetId`。卡牌组件已提供统一的来源、候选、悬停目标、已确认目标和敌技目标状态；后续新增独立的玩家指向随从效果选择流程时应直接复用该状态入口。

## 目标

让玩家在任何存在明确目标的操作或回放帧中，一眼知道“谁正在作用于谁”，而不扩大七随从槽位、不长期遮挡战场，也不改变非定向效果的表现。

## 统一视觉语法

```text
使用者 / 来源（金框 + 来源标签）  →  目标（红框 + 目标标签）
```

| 状态 | 卡牌表现 | 辅助文字 |
| --- | --- | --- |
| 使用者 / 来源 | 实线金框；保留原卡视觉 | `来源`，或 `英雄技能` / `法术` / `随从效果` |
| 候选目标 | 细金色虚线；其余不可选目标变暗 | `可选` |
| 悬停候选目标 | 红色实线预览框 | `目标` |
| 已确认目标 | 红色实线框 + 角标 | `目标` |
| 多目标 | 每个目标均为红框 | `目标 1/2`、`目标 2/2` |
| 非定向效果 | 无来源/目标框和连线 | 保留现有触发、受击、召唤反馈 |

颜色不单独承载含义：每个状态都必须同时有文字标签和边框样式。

## 连线规则

- 连线为短金色箭头，方向始终从来源指向目标。
- 仅在正在选择目标、悬停候选目标，或战斗回放的当前帧中显示。
- 已配置但未正在编辑的敌方英雄技能不常驻画线，只在目标卡上保留红框与 `敌技目标` 小标签。
- 多目标时从同一来源发出多条短箭头；目标超过三个时只保留红框和事件文字，避免遮挡。
- 连线不得拦截鼠标事件、不得覆盖名称、攻血或购买/出售操作区。

## 场景映射

| 场景 | 来源（金框） | 目标（红框） | 额外反馈 |
| --- | --- | --- | --- |
| 玩家英雄技能 | 已激活的英雄技能卡/拖拽影子 | 玩家或敌方战场的具体随从 | 顶部提示显示 `英雄技能 → 选择目标` |
| 玩家酒馆法术 | 正在施放的手牌法术 | 玩家战场的具体随从 | 顶部提示显示法术名与目标名 |
| 指向随从效果 | 施放或触发效果的随从 | 实际被选定的随从 | 效果解析完成后短暂保留结果框 |
| 敌方英雄技能配置 | 敌方英雄技能来源芯片 | 配置的玩家/敌方随从 | 目标卡常驻 `敌技目标`；编辑配置时显示连线 |
| 战斗回放 | 当前帧 `ActorId` 对应的随从 | 当前帧 `TargetId` 对应的随从 | 事件栏显示 `来源名称 → 目标名称` |

## 战斗回放

当前回放帧已有 `ActorId`、`TargetId`、受击对象和触发来源数据。视觉层应把已有数据组合为明确关系：

```text
复活的骑兵（来源，金框） → 饥饿的魔蟒（目标，红框）
```

- 攻击者、技能施放者、效果来源使用金框。
- 直接受击者或显式目标使用红框。
- 间接受击、死亡、召唤、关联对象继续使用现有弱反馈，避免把每个事件都误读为“直接指向”。
- 中间事件栏以实际名称替换通用 `攻击方` / `目标` 芯片；名称缺失时才回退到通用文本。

## 交互与可达性

- 鼠标：开始拖拽/激活定向能力时立即进入候选目标状态；悬停目标显示预览连线；放下或点击后确认。
- 键盘/手柄：焦点在来源时显示 `选择目标` 状态；焦点移动到候选目标时显示红色预览框与目标名称；取消操作清除全部指向反馈。
- 所有装饰性框、箭头与标签必须 `raycastTarget = false`，不得阻碍已有拖放和点击。
- 994×384 下优先保留来源金框、目标红框与两端文字；空间不足时隐藏连线，不隐藏目标标签。

## 实施边界

- 不改变 `GameCommand`、`TargetZone`、`ActorId` 或 `TargetId` 的领域语义。
- 不改变法术、英雄技能、随从效果的结算规则。
- 不把位置选择、买卖、移动、召唤等非定向动作标记为“目标”。
- 不改变法术卡完整卡面和当前卡槽尺寸。

## 建议实施顺序

1. 玩家英雄技能、酒馆法术与指向随从：补齐来源金框、候选目标、已选目标红框和短箭头。
2. 战斗回放：用现有 `ActorId` / `TargetId` 增加来源金框、目标红框、关系箭头和具名事件栏。
3. 敌方英雄技能配置：把已保存的目标映射到实际战场卡，显示 `敌技目标` 红色角标；仅编辑时显示来源连线。
4. 在 1920×1080、1280×720、994×384 下补截图与交互断言。

## 验收标准

- 任一显式定向操作都能在一秒内辨认来源与具体目标。
- 来源始终使用金框，已确认目标始终使用红框。
- 无目标、无效目标、取消定向后不残留红框、金框、箭头或标签。
- 敌方英雄技能配置目标能直接在对应战场随从卡上识别。
- 战斗回放当前帧能同时识别攻击/效果来源与直接目标。
