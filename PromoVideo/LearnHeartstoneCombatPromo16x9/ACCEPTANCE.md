# 验收标准

## G1 可判定标准

- [ ] 输出为 1920×1080、16:9、30fps。
- [ ] 总时长为 60–75 秒。
- [ ] 全程无旁白，主信息仅由真实画面和屏幕文案传达。
- [ ] 成片可包含内嵌 BGM/游戏音效，但不交付独立音频文件。
- [ ] 全程可见“测试版”标识。
- [ ] 结尾明确写出“非官方单人酒馆训练 / 模拟工具”。
- [ ] 每项玩法声明均有当前 Build 的真实截图或连续录屏支撑。
- [ ] 铜须镜头使用已批准的五本真实卡图，不使用原三连/金色镜头。
- [ ] 招募阶段至少有一段连续操作录屏，不用静态截图冒充连续行为。
- [ ] 对手配置和回放控制均使用真实录屏；不得把当前空场回放表述为完整双方战斗。
- [ ] 战斗回放至少展示播放/暂停、步进、跳过、速度或事件日志中的三项。
- [ ] 不出现 Unity Editor、Console、终端、开发者工具、个人路径、调试错误或隐私信息。
- [ ] 不出现“双打”“真实八人大厅”“完整官方模拟器”“100% 还原”等超出范围的表述。
- [ ] 关键文字停留至少 1.2 秒，正文不小于 38px，手机缩放观看仍可读。
- [ ] 画面无黑帧、闪烁、错误裁切；UI 不被转场长时间遮挡。
- [ ] MP4 含 H.264 视频流；本版若保持无音乐方案，允许无音频流。
- [ ] 最终 MP4 记录 SHA256。

## 禁止项

- 未经 G10 人工预览批准直接渲染 high。
- 使用未批准素材、占位图、伪造 UI 或 AI 猜测的功能画面。
- 使用《炉石传说》官方原声或来源不明的音乐。
